## 🌟 عن المشروع (About The Project)

مشروع **amazing.restrunt** هو موقع إلكتروني تعريفي لمطعم يقدم أشهى المأكولات العربية والمشويات الطازجة. تم تصميم الموقع باستخدام **HTML** و **CSS** لتقديم تجربة تصفح بسيطة، وسريعة، ومريحة للمستخدم.

## ✨ مميزات الموقع (Features)

* 🎨 **تصميم بسيط وجذاب:** يبرز قائمة الطعام والأطباق بشكل واضح.
* 📱 **متوافق مع الشاشات:** يسهل تصفحه من الهواتف والأجهزة اللوحية.
* ⚡ **سريع التحميل:** مكوّن من عناصر HTML خفيفة ومنظمة.
